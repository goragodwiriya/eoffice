# E-Office

**ระบบสำนักงานอิเล็กทรอนิกส์สำหรับหน่วยงาน** — จองห้องประชุม จองรถ งานสารบรรณ
ทะเบียนครุภัณฑ์ แจ้งซ่อม และทะเบียนบุคลากร รวมอยู่ในระบบเดียว ใช้บัญชีสมาชิก
แผนก และสิทธิ์ชุดเดียวกันทั้งหมด

รุ่น 7.0.4 · PHP 7.4+ · MySQL / MariaDB · [ข้อตกลงการนำไปใช้งาน](LICENSE): ศึกษา/ทดสอบฟรี · ใช้งานจริง 1,000 บาท · ห้ามขาย

> **English** — E-Office is an office suite for Thai organisations: meeting-room and
> vehicle booking, document circulation (e-document), asset register with asset
> holders, repair requests, and a personnel directory. It runs on
> [Now.js](https://nowjs.net) (HTML-first front-end) and
> [Kotchasan](https://www.kotchasan.com) (PHP back-end), and upgrades databases
> from E-Office 6.x in place. The user interface and documentation are in Thai
> (English UI included). Free to study and test; production use requires a
> 1,000 THB usage fee and reselling is not permitted — see [LICENSE](LICENSE).

## ความสามารถ

| โมดูล | ทำอะไรได้ |
|---|---|
| **จองห้องประชุม** | ปฏิทินห้องว่าง · จองพร้อมอุปกรณ์และวัตถุประสงค์ · อนุมัติหลายขั้นตามสถานะและแผนก · ยกเลิก/ลบตามเงื่อนไขที่ตั้งได้ · แจ้งเตือนผู้เกี่ยวข้อง |
| **จองรถ** | ทะเบียนรถ (ประเภท ยี่ห้อ ที่นั่ง) · จองพร้อมพนักงานขับรถหรือขับเอง · กันคนขับ/รถชนเวลา · อนุมัติหลายขั้น |
| **งานสารบรรณ** | ส่งเอกสารถึงแผนกหรือรายบุคคล · ความเร่งด่วน · เลขที่เอกสารอัตโนมัติ · ติดตามว่าใครรับ/ดาวน์โหลดแล้ว |
| **ทะเบียนครุภัณฑ์** | หมวด ประเภท ยี่ห้อ หน่วย · เลขครุภัณฑ์รายเครื่องพร้อมบาร์โค้ด · **ผู้ใช้งาน/ผู้รับผิดชอบ** ของแต่ละเครื่องพร้อมประวัติการเปลี่ยนมือ · หน้า "อุปกรณ์ของฉัน" · นำเข้า/ส่งออก CSV |
| **แจ้งซ่อม** | สมาชิกแจ้งซ่อมเครื่องที่ตัวเองถือครอง (หรือเครื่องที่ยังไม่มีผู้ถือ) พร้อมไฟล์แนบ · ช่างรับงาน/อัปเดตสถานะ/ค่าใช้จ่าย · ประวัติการซ่อม · พิมพ์ใบรับซ่อมพร้อม QR Code |
| **บุคลากร** | ทำเนียบบุคลากรตามตำแหน่งและแผนก · รหัสพนักงาน (เห็นเฉพาะผู้จัดการ) · รูปถ่าย · ข้อมูลเพิ่มเติม · ส่งออกแล้วแก้ไขนำเข้ากลับด้วย CSV |
| **กลุ่ม Telegram** | ส่งข้อความแจ้งเตือนของแต่ละโมดูลเข้ากลุ่ม Telegram แยกตามแผนก (ใช้แทนกลุ่ม LINE Notify ของรุ่นเก่า ซึ่งปิดบริการไปแล้ว) |

ส่วนที่ทุกโมดูลใช้ร่วมกัน

- **หน้าแรก** — การ์ดสรุป (เอกสารใหม่ ใบจองรออนุมัติ งานซ่อมวันนี้ ฯลฯ) และปฏิทินรวมการจองห้องกับรถ
- **สมาชิกและสิทธิ์** — สถานะสมาชิก แผนก สิทธิ์รายความสามารถ เข้าระบบด้วย Google / Facebook / LINE / Telegram ได้
- **แจ้งเตือน** — อีเมล (เปิด/ปิดอีเมลถึงเจ้าหน้าที่ได้รายโมดูล) · Telegram · LINE · SMS
- **หลายภาษา** — ไทย/อังกฤษ แก้คำแปลผ่านหน้าเว็บได้
- **PWA** — ติดตั้งเป็นแอปบนมือถือได้

## ความต้องการของระบบ

| | ขั้นต่ำ |
|---|---|
| PHP | 7.4 ขึ้นไป · ส่วนขยาย `mbstring` `zlib` `json` `xml` `openssl` `gd` `curl` |
| ฐานข้อมูล | MySQL 5.5.3+ หรือ MariaDB 5.5+ (ต้องรองรับ `utf8mb4`) |
| เว็บเซิร์ฟเวอร์ | Apache + `mod_rewrite` (มี `.htaccess` มาให้) หรือ Nginx ที่เขียนกฎ rewrite เทียบเท่า |

> `Authorization` จะถูกตัดทิ้งก่อนถึง PHP แล้วทุก API ตอบ 401 — `.htaccess`
> ที่ให้มามีทั้ง `CGIPassAuth` และกฎสำรองไว้แล้ว

## ติดตั้งใหม่

1. ดาวน์โหลดหรือ clone โปรเจ็คนี้ แล้วคัดลอกไฟล์ทั้งหมดขึ้นเซิร์ฟเวอร์
2. ตั้งให้โฟลเดอร์ `settings/` และ `datas/` เขียนได้
3. สร้างฐานข้อมูลเปล่าไว้ (แนะนำ charset `utf8mb4`)
4. เปิดเบราว์เซอร์ไปที่ `https://โดเมนของคุณ/install/` แล้วทำตามขั้นตอน
   (ตรวจเซิร์ฟเวอร์ → ตั้งบัญชีผู้ดูแลระบบ → ค่าเชื่อมต่อฐานข้อมูล → สร้างตาราง)
5. **ลบโฟลเดอร์ `install/` ออกเมื่อติดตั้งเสร็จ**
6. เข้าระบบด้วยบัญชีผู้ดูแลที่ตั้งไว้ในขั้นตอนที่ 4

### ข้อมูลตัวอย่าง

การติดตั้งใหม่มีข้อมูลตัวอย่างของทุกโมดูลมาให้ (ห้อง รถ ใบจอง เอกสาร ครุภัณฑ์
งานซ่อม บุคลากร) ไว้ลองใช้งาน แก้หรือลบทิ้งได้ตามปกติ

| สมาชิกตัวอย่าง | สถานะ | บทบาทในข้อมูลตัวอย่าง |
|---|---|---|
| สมชาย ใจดี | บุคลากร | ช่างซ่อม |
| สมศรี รักงาน | บุคลากร | ผู้จัดการห้องประชุม รถ และครุภัณฑ์ |
| วิชัย ขับดี | พนักงานขับรถ | คนขับในใบจองรถ |
| มานี มีสุข | สมาชิก | ผู้แจ้งซ่อม ผู้รับเอกสาร |

สมาชิกตัวอย่าง **ไม่มีรหัสผ่าน** จึงเข้าระบบไม่ได้จนกว่าผู้ดูแลจะตั้งชื่อผู้ใช้และ
รหัสผ่านให้ที่หน้าสมาชิก — การติดตั้งจะไม่สร้างบัญชีที่เดารหัสผ่านได้

## ปรับรุ่นจาก E-Office 6.x

ฐานข้อมูลของ E-Office รุ่นเก่า (Kotchasan 6.x) ปรับรุ่นมาใช้กับรุ่นนี้ได้ทันที
ข้อมูลเดิมไม่หาย ตัวปรับรุ่นนับจำนวนแถวทุกตารางก่อนและหลังให้ดู
และรันซ้ำได้ถ้าค้างกลางทาง

1. **สำรองฐานข้อมูลและไฟล์ของระบบเดิมก่อนเสมอ**
2. วางโค้ดรุ่นนี้ลงในโฟลเดอร์ใหม่ (ไม่แนะนำให้อัปโหลดทับ เพราะรุ่นเก่ามีไฟล์ที่รุ่นนี้ไม่ใช้แล้วจำนวนมาก)
3. คัดลอก `settings/` และ `datas/` จากระบบเดิมมาไว้ในโฟลเดอร์ใหม่ (ค่าเชื่อมต่อฐานข้อมูล ค่ากำหนด และไฟล์แนบ)
4. เปิด `https://โดเมนของคุณ/install/` ตัวติดตั้งจะเข้าโหมดปรับรุ่นเอง เข้าระบบด้วยบัญชีผู้ดูแลระบบเดิม แล้วยืนยันว่าสำรองข้อมูลแล้ว
5. อ่านรายงานผล แล้ว **ลบโฟลเดอร์ `install/`**

สิ่งที่ตัวปรับรุ่นแปลงให้

| ระบบเดิม | รุ่นนี้ |
|---|---|
| ทะเบียนครุภัณฑ์และผู้ใช้งานครุภัณฑ์ | ย้ายเลขครุภัณฑ์และผู้ถือครองมาครบ เปิดยอดคงเหลือให้ · ตารางเดิมเก็บไว้เป็น `*_inventory_stock_bak` ตรวจแล้วลบเองได้ |
| งานซ่อมที่ผูกกับครุภัณฑ์ | ผูกกับเลขครุภัณฑ์ · เลขที่ใบแจ้งซ่อมนับต่อจากเลขเดิม |
| บุคลากร (สมาชิกตามสถานะที่ตั้งไว้) | สร้างทะเบียนบุคลากรพร้อมตำแหน่ง แผนก และข้อมูลเพิ่มเติม |
| สิทธิ์จัดการห้องประชุม · พนักงานขับรถตามสถานะสมาชิก | เปลี่ยนเป็นสิทธิ์ของโมดูลรุ่นนี้ ผู้ใช้เดิมยังทำงานได้เหมือนเดิม |
| กลุ่ม LINE Notify | ย้ายเป็นกลุ่ม Telegram **แบบปิดไว้** — LINE Notify ปิดบริการแล้ว ต้องใส่รหัสแชทของกลุ่ม Telegram แล้วเปิดใช้งานเอง |

หลังปรับรุ่น แนะนำให้ตรวจหน้า **ตั้งค่า** ของแต่ละโมดูล (ขั้นตอนอนุมัติ การส่งอีเมล)
อีกครั้ง

ปรับรุ่นจาก E-Office 7.x รุ่นก่อนหน้า: อัปโหลดไฟล์รุ่นใหม่ทับ แล้วเปิด `/install/` อีกครั้ง

## ตั้งค่าหลังติดตั้ง

| ต้องการ | ไปที่ |
|---|---|
| ชื่อหน่วยงาน โลโก้ ธีม | ตั้งค่า › ทั่วไป / ธีม |
| แผนก ตำแหน่ง | ตั้งค่า › หมวดหมู่ · บุคลากร › หมวดหมู่ |
| ขั้นตอนอนุมัติการจองห้อง/รถ (สถานะผู้อนุมัติ และแผนกของแต่ละขั้น) | ตั้งค่าของโมดูลจองห้อง / จองรถ (ติดตั้งใหม่ตั้งไว้ 1 ขั้นโดยผู้ดูแลระบบ) |
| ใครคือบุคลากร | ตั้งค่าของโมดูลบุคลากร › สถานะสมาชิก — สมาชิกสถานะที่เลือกขึ้นในทะเบียนบุคลากรเอง |
| อีเมลแจ้งเตือน | ตั้งค่า › อีเมล (SMTP) แล้วเปิด/ปิดอีเมลถึงเจ้าหน้าที่ที่ตั้งค่าของแต่ละโมดูล |
| แจ้งเตือนเข้ากลุ่ม Telegram | 1) ตั้งค่า › Telegram ใส่ Bot Token · 2) เพิ่มบอทเข้ากลุ่ม · 3) ตั้งค่า › กลุ่ม Telegram ใส่รหัสแชทของกลุ่ม (ขึ้นต้นด้วย `-100`) เลือกแผนกและโมดูล แล้วกดทดสอบ |

### ทะเบียนบุคลากรด้วยไฟล์ CSV

หน้า **บุคลากร › นำเข้า** มีลิงก์ดาวน์โหลด `personnel.csv` ซึ่งเป็นรายชื่อบุคลากร
ปัจจุบันทั้งหมด (ถ้ายังไม่มีจะได้แถวตัวอย่าง) แก้ไขด้วย Excel หรือ Google Sheets
แล้วนำเข้ากลับได้ทันที

- บุคลากรที่มีอยู่แล้วจะถูก **อัปเดต** — จับคู่ด้วยรหัสพนักงาน หรือด้วยชื่อเมื่อแถวนั้นไม่มีรหัส
- ช่องที่เว้นว่างจะคงค่าเดิมไว้ · ตำแหน่ง/แผนกใส่ได้ทั้งชื่อและรหัส
- แถวใหม่จะสร้างบุคลากรพร้อมบัญชีสมาชิกที่ยังเข้าระบบไม่ได้ จนกว่าผู้ดูแลจะตั้งชื่อผู้ใช้และรหัสผ่านให้

## ถอดโมดูลที่ไม่ใช้

แต่ละโมดูลอยู่ในโฟลเดอร์ของตัวเอง `modules/<ชื่อ>/` คู่กับ `templates/<ชื่อ>/`
ลบทั้งสองโฟลเดอร์ออก เมนู สิทธิ์ และหน้าของโมดูลนั้นจะหายไปเอง ไม่ต้องแก้ไฟล์อื่น

| โมดูล | โฟลเดอร์ | หมายเหตุ |
|---|---|---|
| จองห้องประชุม | `booking` | |
| จองรถ | `car` | |
| งานสารบรรณ | `edocument` | |
| ทะเบียนครุภัณฑ์ | `inventory` | แจ้งซ่อมใช้ทะเบียนนี้ — ถ้าถอด `inventory` ต้องถอด `repair` ด้วย |
| แจ้งซ่อม | `repair` | |
| บุคลากร | `personnel` | |
| กลุ่ม Telegram | `telegramgroup` | |

ถอดก่อนติดตั้งใหม่ ตารางของโมดูลนั้นจะไม่ถูกสร้าง ข้อมูลตัวอย่างของโมดูลอื่นที่อ้างถึง
สมาชิกตัวอย่าง (อยู่ในไฟล์ของ `personnel`) จะไม่มีชื่อผู้ทำรายการ

## สำหรับนักพัฒนา

ชุดทดสอบทั้งหมดรันกับ MySQL/MariaDB จริง โดยใช้ค่าเชื่อมต่อใน `settings/database.php`
(สร้างฐานทดสอบแยกต่างหาก แล้วลบทิ้งเมื่อจบ ไม่แตะฐานข้อมูลที่ใช้งานจริง)


## ข้อตกลงการนำไปใช้งาน

- สามารถนำไปศึกษาและทดสอบได้ฟรี
- สามารถพัฒนาต่อยอดได้
- การนำไปใช้งานจริง ไม่ว่าจะพัฒนาเพิ่มเติมหรือไม่ ต้องชำระค่านำไปใช้ **1,000 บาท** (หนึ่งพันบาทถ้วน)
- **ห้ามขาย** ถ้าต้องการนำไปพัฒนาต่อเพื่อขาย ให้ติดต่อผู้เขียนก่อน
- รับพัฒนาเพิ่มเติมให้ตรงกับความต้องการ (มีค่าใช้จ่าย)
- แจ้งปัญหา หรือมีข้อสงสัย สอบถามได้ที่บอร์ดของคชสาร [kotchasan.com](https://www.kotchasan.com)
- ผู้เขียนไม่รับผิดชอบข้อผิดพลาดใด ๆ ในการใช้งาน
